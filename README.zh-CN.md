这是一个基于 Swift Charts、面向 iOS 17+ 和 macOS 14+ 上 SwiftUI 的 Swift 图表视图软件包。它涵盖了 Swift Charts 留给开发者自行实现的图表：包含数万个数据点的时间序列、直方图、箱线图、趋势线、K 线图、瀑布图、热力图、雷达图、树状图和实时行情图，并且公开了这些图表背后的分析逻辑，因此你也可以把它用在自己的 `Chart` 中。该软件包没有任何依赖。

## 亮点

- **10 种图表视图**：`TimeSeriesChart`、`HistogramChart`、`BoxPlotChart`、`ScatterChart`、`CandlestickChart`、`WaterfallChart`、`HeatmapChart`、`RadarChart`、`TreemapChart` 和 `LiveTickerChart`。每种图表都接收普通的值类型，只需要设置 frame。
- **大规模数据与实时数据**：`TimeSeriesChart` 使用 Largest-Triangle-Three-Buckets 将每个序列降采样到 1,000 个点，因此每个序列 50,000 条读数仍然流畅；它可以在时间窗口内滚动，并报告所选日期。`LiveSeries` 将最新的值保存在环形缓冲区中，供 `LiveTickerChart` 使用。
- **分析逻辑完全公开**：`Histogram`（Sturges、Freedman–Diaconis、固定宽度或固定数量）、`BoxPlotSummary`（Tukey 须线）、`Statistics`、`LinearRegression`、`MovingAverage`、`NiceScale` 坐标轴刻度、`TreemapLayout`（squarified）、`Candle.aggregate` 和 `Downsampling`。
- **任何输入都安全**：非有限值以及公元 1 年至 4001 年范围之外的日期会被排除；绝对值超过 1e307 的有限值绘制在 ±1e307 处；接近 `Double.greatestFiniteMagnitude` 的范围以及次正规数范围仍保持有限；刻度数量、分箱、缓冲区、滚动窗口数量和导出都设有上限。专门的测试套件会向分析类型和图表输入 `nan`、无穷大、`Int.max`、极端范围和极端日期。
- **无障碍**：基于 Swift Charts 的视图支持 VoiceOver 导航和 Audio Graphs，并为分箱、箱体、K 线和步骤提供可读的标签；基于 Canvas 的视图（雷达图、树状图、行情图）附带 `AudioGraphDescriptor`。内置对色盲友好的配色。
- **经过测试**：33 个测试套件中的 188 个 Swift Testing 测试，在 macOS 和 iPhone 模拟器上运行，其中包括在浅色和深色模式下对 README 中每个示例进行的离屏渲染。
- **可编译的使用示例**：下面的每个示例都来自[示例应用](Examples/ChartGallery)，CI 会为 iOS 和 macOS 构建它。

## 快速开始

**1. 添加软件包**

在 Xcode 中选择 **File › Add Package Dependencies…**，然后输入仓库地址：

```text
https://github.com/muhittincamdali/SwiftUI-Data-Visualization.git
```

将地址粘贴到窗口右上角的搜索框中。保持 **Dependency Rule** 为 **Up to Next Major Version**，起始版本为 `2.0.0`，然后点击 **Add Package**。在下一个窗口中，在 **SwiftUIDataVisualization** 旁选择你的应用 target，再次点击 **Add Package**。

**2. 导入模块**

```swift
import SwiftUIDataVisualization
```

将这一行放在你绘制图表的 Swift 文件顶部，位于 `import SwiftUI` 之下。

**3. 开始使用**

在新建的 Xcode 应用中（**File › New › Project… › App**），将 `ContentView.swift` 中的全部内容替换为：

```swift
import SwiftUI
import SwiftUIDataVisualization

struct ContentView: View {
    let steps = TimeSeries(
        name: "Steps",
        values: [4_200, 8_100, 6_900, 10_400, 7_800, 12_100, 9_300],
        start: .now.addingTimeInterval(-6 * 86_400),
        interval: 86_400
    )

    var body: some View {
        TimeSeriesChart(steps)
            .frame(height: 240)
            .padding()
    }
}
```

点击 **Run**（⌘R）。应用会显示最近七天的一条蓝色折线；触摸这条线（在 Mac 上将鼠标悬停其上），即可看到日期和步数。

## 安装

### Swift Package Manager

在 Xcode 中选择 **File › Add Package Dependencies…**，然后输入仓库地址：

```text
https://github.com/muhittincamdali/SwiftUI-Data-Visualization.git
```

或者将其添加到 `Package.swift` 的 `dependencies` 中：

```swift
dependencies: [
    .package(url: "https://github.com/muhittincamdali/SwiftUI-Data-Visualization.git", from: "2.0.0")
],
targets: [
    .target(name: "YourApp", dependencies: [
        .product(name: "SwiftUIDataVisualization", package: "SwiftUI-Data-Visualization")
    ])
]
```

2.0.0 版本（2026 年 10 月）是这里所述图表的首个发布版本。之前的 1.0.0 版本使用了不同的 API，无法在当前的 Xcode 版本中构建；2.0.0 还整合了即将归档的 SwiftUI-Charts-Pro 的成果。[CHANGELOG.md](CHANGELOG.md) 列出了所有变更，包括不兼容的变更。

## 使用方法

下面的示例复制自 [`Examples/ChartGallery/ChartGallery/ReadmeSamples.swift`](Examples/ChartGallery/ChartGallery/ReadmeSamples.swift)。示例应用和测试套件都会编译该文件。

### 时间序列

```swift
struct ServerLoad: View {
    // 50,000 readings per server, one every 30 seconds; the chart draws 1,000 of each.
    let servers = [readings(name: "api-1", phase: 0), readings(name: "api-2", phase: 1)]

    static func readings(name: String, phase: Double) -> TimeSeries {
        let values = (0..<50_000).map { index -> Double in
            let wave = 25 * sin(Double(index) / 3_000 + phase)
            let noise = Double(index % 97) / 40
            return 40 + wave + noise
        }
        return TimeSeries(name: name, values: values, start: Date(timeIntervalSinceReferenceDate: 800_000_000), interval: 30)
    }

    var body: some View {
        TimeSeriesChart(servers, movingAverageWindow: 2_000)
            .frame(height: 240)
            .padding()
    }
}
```

虚线是基于 2,000 条读数的移动平均线。传入 `style: .area` 可以填充折线下方的区域。

### 滚动、选择与导出

```swift
struct ScrollingHistory: View {
    @State private var selected: Date?
    @State private var exported: Data?
    let load = ServerLoad.readings(name: "api-1", phase: 0)

    var chart: some View {
        // Two days at a time out of 17; the chart opens at the newest data.
        TimeSeriesChart(load, selection: $selected, visibleDuration: 2 * 86_400)
    }

    var body: some View {
        VStack(alignment: .leading, spacing: 12) {
            Text(selected.map { "Selected \($0.formatted(date: .abbreviated, time: .shortened))" } ?? "Touch the chart")
                .font(.headline)
            chart
                .frame(height: 220)
            Button("Export PNG") {
                exported = ChartExport.pngData(of: chart, size: CGSize(width: 600, height: 300))
            }
            if let exported {
                Text("\(exported.count) bytes")
            }
        }
        .padding()
    }
}
```

### 统计

```swift
struct LatencyReport: View {
    let ios: [Double] = [112, 98, 130, 101, 145, 120, 99, 180, 104, 117, 125, 133, 230, 108, 121]
    let android: [Double] = [140, 151, 128, 160, 149, 171, 138, 155, 162, 147, 158, 133, 166, 152]

    var body: some View {
        VStack(spacing: 24) {
            HistogramChart(values: ios + android, binning: .width(25), valueLabel: "Latency (ms)")
                .frame(height: 180)
            BoxPlotChart([
                .init(name: "iOS", values: ios),
                .init(name: "Android", values: android),
            ], valueLabel: "Latency (ms)")
            .frame(height: 200)
        }
        .padding()
    }
}
```

未指定 `binning` 时，直方图会使用 Sturges 或 Freedman–Diaconis 规则来确定分箱宽度，以得到更多分箱的那个为准。箱线图会把超出 1.5 倍四分位距的值标记为离群值。

### 金融

```swift
struct PriceAndProfit: View {
    // Trades every 5 minutes for three days, grouped into one candle per 6 hours.
    let candles = Candle.aggregate(trades, interval: 6 * 3_600)

    static let trades = (0..<864).map { index -> TimeSeriesPoint in
        let date = Date(timeIntervalSinceReferenceDate: 800_000_000 + Double(index) * 300)
        let price = 100 + 6 * sin(Double(index) / 40) + Double(index % 13) / 4
        return TimeSeriesPoint(date: date, value: price)
    }

    var body: some View {
        VStack(spacing: 24) {
            CandlestickChart(candles)
                .frame(height: 200)
            WaterfallChart([
                WaterfallStep("Revenue", 420),
                WaterfallStep("Costs", -260),
                WaterfallStep("Tax", -40),
                .total("Profit"),
            ])
            .frame(height: 200)
        }
        .padding()
    }
}
```

struct CommitActivity: View {

### 实时数据

```swift
struct LiveLoad: View {
    @State private var load = LiveSeries(capacity: 120)

    var body: some View {
        LiveTickerChart(values: load.values, title: "CPU load")
            .frame(height: 80)
            .padding()
            .task {
                var tick = 0.0
                while !Task.isCancelled {
                    tick += 1
                    load.append(50 + 30 * sin(tick / 8)) // read the real value here
                    try? await Task.sleep(for: .milliseconds(100))
                }
            }
    }
}
```

## 架构

- `Sources/SwiftUIDataVisualization/Charts/` 为每个图表视图提供一个文件。其中七个是 Swift Charts 的 `Chart`；`RadarChart`、`TreemapChart` 和 `LiveTickerChart` 使用 `Canvas` 或普通视图绘制，因为 Swift Charts 没有极坐标或树状图坐标，而且以显示刷新率重绘的行情图在一次 `Canvas` 绘制中完成开销更低。
- `Analysis/`、`Layout/` 和 `Data/` 存放图表所使用的值类型和函数（`Histogram`、`BoxPlotSummary`、`LinearRegression`、`NiceScale`、`TreemapLayout`、`Candle` 等）。它们不含视图代码，并且是 `Sendable` 的，因此可以在主 actor 之外运行。
- 每个图表在绘制之前所做的准备工作（降采样、须线范围、K 线实体宽度、瀑布图柱条、雷达图最大值）都放在 `nonisolated static` 函数中，测试会直接调用这些函数。
- `Streaming/` 包含 `RingBuffer` 和 `LiveSeries`；`LiveSeries` 是唯一的引用类型，是运行在主 actor 上的 `@Observable` 类。`Style/ChartPalette.swift` 通过环境（environment）传递颜色。
- CI 会在 macOS 上运行 `swift test`，在 iPhone 模拟器上运行 `xcodebuild test`，为 iOS 和 macOS 构建示例应用，并发布 DocC 文档。

在本地运行测试：

```sh
swift test                                    # macOS
xcodebuild test -scheme SwiftUIDataVisualization \
  -destination 'platform=iOS Simulator,name=iPhone 17'
```
