Um pacote Swift de views de gráficos para SwiftUI no iOS 17+ e macOS 14+, feito com Swift Charts. Ele cobre os gráficos que o Swift Charts deixa por sua conta (séries temporais com dezenas de milhares de pontos, histogramas, box plots, linhas de tendência, candlesticks, cascatas, mapas de calor, gráficos de radar, treemaps e tickers ao vivo) e torna pública a análise por trás deles, para que você possa usá-la em um `Chart` próprio. O pacote não tem dependências.

## Destaques

- **10 views de gráficos** — `TimeSeriesChart`, `HistogramChart`, `BoxPlotChart`, `ScatterChart`,
  `CandlestickChart`, `WaterfallChart`, `HeatmapChart`, `RadarChart`, `TreemapChart` e
  `LiveTickerChart`. Cada uma recebe tipos de valor simples e só precisa de um frame.
- **Dados grandes e ao vivo** — o `TimeSeriesChart` reduz cada série a 1.000 pontos com
  Largest-Triangle-Three-Buckets, então 50.000 leituras por série continuam fluidas; ele pode rolar por
  uma janela de tempo e informar a data selecionada. O `LiveSeries` mantém os valores mais recentes em
  um buffer circular para o `LiveTickerChart`.
- **A análise é pública** — `Histogram` (Sturges, Freedman–Diaconis, largura fixa ou quantidade fixa),
  `BoxPlotSummary` (bigodes de Tukey), `Statistics`, `LinearRegression`, `MovingAverage`,
  as marcas de eixo do `NiceScale`, `TreemapLayout` (squarified), `Candle.aggregate` e `Downsampling`.
- **Seguro com qualquer entrada** — valores não finitos e datas fora dos anos 1 a 4001 são
  deixados de fora, valores finitos além de ±1e307 são desenhados nesse limite,
  intervalos próximos de `Double.greatestFiniteMagnitude` e intervalos
  subnormais continuam finitos, e a quantidade de marcas, os intervalos (bins), os buffers, as
  janelas de rolagem e as exportações têm limites superiores. Uma suíte de testes dedicada envia
  `nan`, infinito, `Int.max`, intervalos extremos e datas extremas aos tipos de análise e aos
  gráficos.
- **Acessível** — as views baseadas em Swift Charts têm navegação com VoiceOver e Audio Graphs, com
  rótulos legíveis para intervalos, caixas, candles e etapas; as views baseadas em Canvas (radar,
  treemap, ticker) anexam um `AudioGraphDescriptor`. Uma paleta segura para daltonismo já vem incluída.
- **Testado** — 188 testes de Swift Testing em 33 suítes, executados no macOS e em um simulador de
  iPhone, incluindo renderizações fora da tela de cada exemplo do README nos modos claro e escuro.
- **Exemplos de uso que compilam** — todos os exemplos abaixo vêm do
  [app de exemplo](Examples/ChartGallery), que o CI compila para iOS e macOS.

## Início rápido

**1. Adicione o pacote**

No Xcode, escolha **File › Add Package Dependencies…** e informe a URL do repositório:

```text
https://github.com/muhittincamdali/SwiftUI-Data-Visualization.git
```

Cole-a no campo de busca no canto superior direito da janela. Deixe **Dependency Rule** em **Up to Next Major Version** a partir de `2.0.0` e clique em **Add Package**. Na janela seguinte, escolha o target do seu app ao lado de **SwiftUIDataVisualization** e clique em **Add Package** de novo.

**2. Importe o módulo**

```swift
import SwiftUIDataVisualization
```

Coloque esta linha no topo do arquivo Swift em que você desenha um gráfico, abaixo de `import SwiftUI`.

**3. Use**

Em um app novo do Xcode (**File › New › Project… › App**), substitua todo o conteúdo de `ContentView.swift` por:

```swift
import SwiftUI
import SwiftUIDataVisualization

struct ContentView: View {
    let steps = TimeSeries(
        name: "Steps",
        values: [4_200, 8_100, 6_900, 10_400, 7_800, 12_100, 9_300],
        start: .now.addingTimeInterval(-6 * 86_400),
        interval: 86_400
    )

    var body: some View {
        TimeSeriesChart(steps)
            .frame(height: 240)
            .padding()
    }
}
```

Pressione **Run** (⌘R). O app mostra uma linha azul dos últimos sete dias; toque na linha (ou passe o ponteiro sobre ela no Mac) para ver a data e o número de passos.

No Xcode, escolha **File › Add Package Dependencies…** e informe a URL do repositório:

```text
https://github.com/muhittincamdali/SwiftUI-Data-Visualization.git
```

Ou adicione-o às `dependencies` do seu `Package.swift`:

```swift
dependencies: [

    .target(name: "YourApp", dependencies: [
        .product(name: "SwiftUIDataVisualization", package: "SwiftUI-Data-Visualization")

]
```

### Séries temporais

```swift
struct ServerLoad: View {
    // 50,000 readings per server, one every 30 seconds; the chart draws 1,000 of each.
    let servers = [readings(name: "api-1", phase: 0), readings(name: "api-2", phase: 1)]

    static func readings(name: String, phase: Double) -> TimeSeries {
        let values = (0..<50_000).map { index -> Double in
            let wave = 25 * sin(Double(index) / 3_000 + phase)
            let noise = Double(index % 97) / 40
            return 40 + wave + noise
        }
        return TimeSeries(name: name, values: values, start: Date(timeIntervalSinceReferenceDate: 800_000_000), interval: 30)
    }

    var body: some View {
        TimeSeriesChart(servers, movingAverageWindow: 2_000)
            .frame(height: 240)
            .padding()
    }
}
```

As linhas tracejadas são as médias móveis de 2.000 leituras. Passe `style: .area` para preencher a área abaixo das linhas.

### Rolagem, seleção e exportação

```swift
struct ScrollingHistory: View {
    @State private var selected: Date?
    @State private var exported: Data?
    let load = ServerLoad.readings(name: "api-1", phase: 0)

    var chart: some View {
        // Two days at a time out of 17; the chart opens at the newest data.
        TimeSeriesChart(load, selection: $selected, visibleDuration: 2 * 86_400)
    }

    var body: some View {
        VStack(alignment: .leading, spacing: 12) {
            Text(selected.map { "Selected \($0.formatted(date: .abbreviated, time: .shortened))" } ?? "Touch the chart")
                .font(.headline)
            chart
                .frame(height: 220)
            Button("Export PNG") {
                exported = ChartExport.pngData(of: chart, size: CGSize(width: 600, height: 300))
            }
            if let exported {
                Text("\(exported.count) bytes")
            }
        }
        .padding()
    }
}
```

### Estatística

```swift
struct LatencyReport: View {
    let ios: [Double] = [112, 98, 130, 101, 145, 120, 99, 180, 104, 117, 125, 133, 230, 108, 121]
    let android: [Double] = [140, 151, 128, 160, 149, 171, 138, 155, 162, 147, 158, 133, 166, 152]

    var body: some View {
        VStack(spacing: 24) {
            HistogramChart(values: ios + android, binning: .width(25), valueLabel: "Latency (ms)")
                .frame(height: 180)
            BoxPlotChart([
                .init(name: "iOS", values: ios),
                .init(name: "Android", values: android),
            ], valueLabel: "Latency (ms)")
            .frame(height: 200)
        }
        .padding()
    }
}
```

Sem `binning`, o histograma escolhe a largura dos intervalos pela regra de Sturges ou pela de Freedman–Diaconis, a que gerar mais intervalos. O box plot marca os valores além de 1,5 vez a amplitude interquartil como outliers.

### Finanças

```swift
struct PriceAndProfit: View {
    // Trades every 5 minutes for three days, grouped into one candle per 6 hours.
    let candles = Candle.aggregate(trades, interval: 6 * 3_600)

    static let trades = (0..<864).map { index -> TimeSeriesPoint in
        let date = Date(timeIntervalSinceReferenceDate: 800_000_000 + Double(index) * 300)
        let price = 100 + 6 * sin(Double(index) / 40) + Double(index % 13) / 4
        return TimeSeriesPoint(date: date, value: price)
    }

    var body: some View {
        VStack(spacing: 24) {
            CandlestickChart(candles)
                .frame(height: 200)
            WaterfallChart([
                WaterfallStep("Revenue", 420),
                WaterfallStep("Costs", -260),
                WaterfallStep("Tax", -40),
                .total("Profit"),
            ])
            .frame(height: 200)
        }
        .padding()
    }
}
```

```swift
struct CommitActivity: View {
    let days = ["Mon", "Tue", "Wed", "Thu", "Fri"]
    let hours = ["9", "11", "13", "15", "17"]

    var cells: [HeatmapCell] {
        days.enumerated().flatMap { day, dayName in
```

### Dados ao vivo

```swift
struct LiveLoad: View {
    @State private var load = LiveSeries(capacity: 120)

    var body: some View {
        LiveTickerChart(values: load.values, title: "CPU load")
            .frame(height: 80)
            .padding()
            .task {
                var tick = 0.0
                while !Task.isCancelled {
                    tick += 1
                    load.append(50 + 30 * sin(tick / 8)) // read the real value here
                    try? await Task.sleep(for: .milliseconds(100))
                }
            }
    }
}
```

## Arquitetura

- `Sources/SwiftUIDataVisualization/Charts/` tem um arquivo por view de gráfico. Sete delas são
  `Chart`s do Swift Charts; `RadarChart`, `TreemapChart` e `LiveTickerChart` desenham com `Canvas`
  ou com views simples, porque o Swift Charts não tem coordenadas polares nem de treemap, e um ticker
  redesenhado na taxa de atualização da tela custa menos em uma única passada de `Canvas`.
- `Analysis/`, `Layout/` e `Data/` reúnem os tipos de valor e as funções que os gráficos usam
  (`Histogram`, `BoxPlotSummary`, `LinearRegression`, `NiceScale`, `TreemapLayout`, `Candle`, …). Não
  têm código de view e são `Sendable`, então podem rodar fora do actor principal.
- A preparação que cada gráfico faz antes de desenhar (redução de amostragem, domínios dos bigodes,
  larguras dos corpos dos candles, barras da cascata, máximo do radar) fica em funções
  `nonisolated static` que os testes chamam diretamente.
- `Streaming/` tem `RingBuffer` e `LiveSeries`, o único tipo de referência, uma classe `@Observable`
  no actor principal. `Style/ChartPalette.swift` repassa as cores pelo ambiente (environment).
- O CI executa `swift test` no macOS e `xcodebuild test` em um simulador de iPhone, compila o app de
  exemplo para iOS e macOS e publica a documentação do DocC.

Execute os testes localmente:

```sh
swift test                                    # macOS
xcodebuild test -scheme SwiftUIDataVisualization \
  -destination 'platform=iOS Simulator,name=iPhone 17'
```
