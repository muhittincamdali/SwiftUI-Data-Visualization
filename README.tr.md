iOS 17+ ve macOS 14+ üzerinde SwiftUI için, Swift Charts tabanlı bir Swift paketi. Swift Charts'ın size bıraktığı grafikleri kapsar: on binlerce noktalı zaman serileri, histogramlar, kutu grafikleri, trend çizgileri, mum grafikleri, şelale grafikleri, ısı haritaları, radar grafikleri, treemap'ler ve canlı göstergeler. Bunların arkasındaki analizi de herkese açık sunar; böylece kendi `Chart`'ınızda kullanabilirsiniz. Paketin hiçbir bağımlılığı yoktur.

## Öne çıkanlar

- **10 grafik görünümü** — `TimeSeriesChart`, `HistogramChart`, `BoxPlotChart`, `ScatterChart`,
  `CandlestickChart`, `WaterfallChart`, `HeatmapChart`, `RadarChart`, `TreemapChart` ve
  `LiveTickerChart`. Her biri düz değer tipleri alır ve yalnızca bir frame ister.
- **Büyük ve canlı veri** — `TimeSeriesChart`, her seriyi Largest-Triangle-Three-Buckets ile
  1.000 noktaya indirger; böylece seri başına 50.000 okuma akıcı kalır. Bir zaman penceresi
  boyunca kaydırılabilir ve seçilen tarihi bildirebilir. `LiveSeries`, en son değerleri
  `LiveTickerChart` için bir halka tamponda tutar.
- **Analiz herkese açık** — `Histogram` (Sturges, Freedman–Diaconis, sabit genişlik veya sayı),
  `BoxPlotSummary` (Tukey bıyıkları), `Statistics`, `LinearRegression`, `MovingAverage`,
  `NiceScale` eksen işaretleri, `TreemapLayout` (squarified), `Candle.aggregate` ve `Downsampling`.
- **Her girdiyle güvenli** — sonlu olmayan değerler ve 1 ile 4001 yılları dışındaki tarihler
  dışarıda bırakılır, `Double.greatestFiniteMagnitude` yakınındaki ve denormal aralıklar sonlu
  kalır; işaret sayıları, aralıklar (bin), tamponlar, kaydırma pencereleri ve dışa aktarmalar için
  üst sınırlar vardır. Ayrı bir test paketi, analiz tiplerine ve grafiklere `nan`, sonsuz,
  `Int.max`, uç aralıklar ve uç tarihler verir.
- **Erişilebilir** — Swift Charts tabanlı görünümler VoiceOver gezintisi ve Audio Graphs desteği
  alır; aralıklar, kutular, mumlar ve adımlar için okunabilir etiketler sunar. Canvas tabanlı
  görünümler (radar, treemap, ticker) bir `AudioGraphDescriptor` ekler. Renk körlerine uygun bir
  palet yerleşik gelir.
- **Test edilmiş** — 32 suite içinde 180 Swift Testing testi, macOS'ta ve bir iPhone
  simülatöründe çalışır; README'deki her örneğin açık ve koyu modda ekran dışı çizimleri de
  dahildir.
- **Derlenen kullanım örnekleri** — aşağıdaki her örnek, CI'ın iOS ve macOS için derlediği
  [örnek uygulamadan](Examples/ChartGallery) gelir.

## Hızlı başlangıç

**1. Paketi ekleyin**

Xcode'da **File › Add Package Dependencies…** menüsünü seçin ve depo adresini girin:

```text
https://github.com/muhittincamdali/SwiftUI-Data-Visualization.git
```

Adresi pencerenin sağ üstündeki arama alanına yapıştırın. **Dependency Rule** ayarını `2.0.0` sürümünden itibaren **Up to Next Major Version** olarak bırakın, ardından **Add Package**'a tıklayın. Açılan pencerede **SwiftUIDataVisualization** yanından uygulama hedefinizi seçin ve yeniden **Add Package**'a tıklayın.

**2. Modülü içe aktarın**

```swift
import SwiftUIDataVisualization
```

Bu satırı, grafiği çizdiğiniz Swift dosyasının en üstüne, `import SwiftUI` satırının altına ekleyin.

**3. Kullanın**

Yeni bir Xcode uygulamasında (**File › New › Project… › App**) `ContentView.swift` dosyasının tüm içeriğini şununla değiştirin:

```swift
import SwiftUI
import SwiftUIDataVisualization

struct ContentView: View {
    let steps = TimeSeries(
        name: "Steps",
        values: [4_200, 8_100, 6_900, 10_400, 7_800, 12_100, 9_300],
        start: .now.addingTimeInterval(-6 * 86_400),
        interval: 86_400
    )

    var body: some View {
        TimeSeriesChart(steps)
            .frame(height: 240)
            .padding()
    }
}
```

**Run**'a (⌘R) basın. Uygulama, son yedi günün mavi çizgisini gösterir; tarihi ve adım sayısını görmek için çizgiye dokunun (Mac'te üzerine gelin).

### Swift Package Manager

Xcode'da **File › Add Package Dependencies…** menüsünü seçin ve depo adresini girin:

```text
https://github.com/muhittincamdali/SwiftUI-Data-Visualization.git
```

Ya da `Package.swift` dosyanızdaki `dependencies` listesine ekleyin:

```swift
dependencies: [
    .package(url: "https://github.com/muhittincamdali/SwiftUI-Data-Visualization.git", from: "2.0.0")
],
targets: [
    .target(name: "YourApp", dependencies: [
        .product(name: "SwiftUIDataVisualization", package: "SwiftUI-Data-Visualization")
    ])
]
```

2.0.0 sürümü (Ekim 2026), burada anlatılan grafiklerin ilk sürümüdür. Önceki sürüm 1.0.0'ın API'si farklıydı ve güncel Xcode sürümleriyle derlenmiyordu; 2.0.0 ayrıca arşivlenmekte olan SwiftUI-Charts-Pro'nun çalışmalarını da içerir. Geriye dönük uyumsuz olanlar dahil tüm değişiklikler [CHANGELOG.md](CHANGELOG.md) dosyasında listelenir.

### Zaman serisi

```swift
struct ServerLoad: View {
    // 50,000 readings per server, one every 30 seconds; the chart draws 1,000 of each.
    let servers = [readings(name: "api-1", phase: 0), readings(name: "api-2", phase: 1)]

    static func readings(name: String, phase: Double) -> TimeSeries {
        let values = (0..<50_000).map { index -> Double in
            let wave = 25 * sin(Double(index) / 3_000 + phase)
            let noise = Double(index % 97) / 40
            return 40 + wave + noise
        }
        return TimeSeries(name: name, values: values, start: Date(timeIntervalSinceReferenceDate: 800_000_000), interval: 30)
    }

    var body: some View {
        TimeSeriesChart(servers, movingAverageWindow: 2_000)
            .frame(height: 240)
            .padding()
    }
}
```

Kesikli çizgiler, 2.000 okumalık hareketli ortalamalardır. Çizgilerin altını doldurmak için `style: .area` verin.

### Kaydırma, seçim ve dışa aktarma

```swift
struct ScrollingHistory: View {
    @State private var selected: Date?
    @State private var exported: Data?
    let load = ServerLoad.readings(name: "api-1", phase: 0)

    var chart: some View {
        // Two days at a time out of 17; the chart opens at the newest data.
        TimeSeriesChart(load, selection: $selected, visibleDuration: 2 * 86_400)
    }

    var body: some View {
        VStack(alignment: .leading, spacing: 12) {
            Text(selected.map { "Selected \($0.formatted(date: .abbreviated, time: .shortened))" } ?? "Touch the chart")
                .font(.headline)
            chart
                .frame(height: 220)
            Button("Export PNG") {
                exported = ChartExport.pngData(of: chart, size: CGSize(width: 600, height: 300))
            }
            if let exported {
                Text("\(exported.count) bytes")
            }
        }
        .padding()
    }
}
```

### İstatistik

```swift
struct LatencyReport: View {
    let ios: [Double] = [112, 98, 130, 101, 145, 120, 99, 180, 104, 117, 125, 133, 230, 108, 121]
    let android: [Double] = [140, 151, 128, 160, 149, 171, 138, 155, 162, 147, 158, 133, 166, 152]

    var body: some View {
        VStack(spacing: 24) {
            HistogramChart(values: ios + android, binning: .width(25), valueLabel: "Latency (ms)")
                .frame(height: 180)
            BoxPlotChart([
                .init(name: "iOS", values: ios),
                .init(name: "Android", values: android),
            ], valueLabel: "Latency (ms)")
            .frame(height: 200)
        }
        .padding()
    }
}
```

`binning` verilmezse histogram, aralık genişliğini Sturges veya Freedman–Diaconis kuralıyla seçer; hangisi daha çok aralık verirse onu kullanır. Kutu grafiği, 1,5 çeyrekler açıklığından uzaktaki değerleri aykırı değer olarak işaretler.

### Finans

```swift
struct PriceAndProfit: View {
    // Trades every 5 minutes for three days, grouped into one candle per 6 hours.
    let candles = Candle.aggregate(trades, interval: 6 * 3_600)

    static let trades = (0..<864).map { index -> TimeSeriesPoint in
        let date = Date(timeIntervalSinceReferenceDate: 800_000_000 + Double(index) * 300)
        let price = 100 + 6 * sin(Double(index) / 40) + Double(index % 13) / 4
        return TimeSeriesPoint(date: date, value: price)
    }

    var body: some View {
        VStack(spacing: 24) {
            CandlestickChart(candles)
                .frame(height: 200)
            WaterfallChart([
                WaterfallStep("Revenue", 420),
                WaterfallStep("Costs", -260),
                WaterfallStep("Tax", -40),
                .total("Profit"),
            ])
            .frame(height: 200)
        }
        .padding()
    }
}
```

### Isı haritası

```swift
struct CommitActivity: View {
    let days = ["Mon", "Tue", "Wed", "Thu", "Fri"]
    let hours = ["9", "11", "13", "15", "17"]

    var cells: [HeatmapCell] {
        days.enumerated().flatMap { day, dayName in
            hours.enumerated().map { hour, hourName in
                HeatmapCell(column: hourName, row: dayName, value: Double((day * 7 + hour * 3) % 11))
            }
        }
    }

    var body: some View {
        HeatmapChart(cells, valueLabel: "Commits", showsValues: true)
            .frame(height: 220)
            .padding()
    }
}
```

### Canlı veri

```swift
struct LiveLoad: View {
    @State private var load = LiveSeries(capacity: 120)

    var body: some View {
        LiveTickerChart(values: load.values, title: "CPU load")
            .frame(height: 80)
            .padding()
            .task {
                var tick = 0.0
                while !Task.isCancelled {
                    tick += 1
                    load.append(50 + 30 * sin(tick / 8)) // read the real value here
                    try? await Task.sleep(for: .milliseconds(100))
                }
            }
    }
}
```

### Renkler

```swift
struct ColorblindSafeCharts: View {
    var body: some View {
        LatencyReport()
            .chartPalette(.colorblindSafe)
    }
}
```

## Mimari

- `Sources/SwiftUIDataVisualization/Charts/` her grafik görünümü için bir dosya içerir. Bunların
  yedisi Swift Charts `Chart`'ıdır; `RadarChart`, `TreemapChart` ve `LiveTickerChart` ise `Canvas`
  ya da düz görünümlerle çizer; çünkü Swift Charts'ta kutupsal veya treemap koordinatları yoktur
  ve ekranın yenileme hızında yeniden çizilen bir ticker'ı tek bir `Canvas` geçişinde çizmek
  daha ucuzdur.
- `Analysis/`, `Layout/` ve `Data/`, grafiklerin kullandığı değer tiplerini ve fonksiyonları
  içerir (`Histogram`, `BoxPlotSummary`, `LinearRegression`, `NiceScale`, `TreemapLayout`,
  `Candle`, …). Görünüm kodu içermezler ve `Sendable` oldukları için ana aktör dışında çalışabilirler.
- Her grafiğin çizimden önce yaptığı hazırlık (aşağı örnekleme, bıyık alanları, mum gövde
  genişlikleri, şelale çubukları, radar azami değeri), testlerin doğrudan çağırdığı
  `nonisolated static` fonksiyonlarda bulunur.
- `Streaming/` içinde `RingBuffer` ve tek referans tipi olan `LiveSeries` bulunur; `LiveSeries`,
  ana aktörde çalışan `@Observable` bir sınıftır. `Style/ChartPalette.swift` renkleri ortam
  (environment) üzerinden iletir.
- CI, macOS'ta `swift test`, bir iPhone simülatöründe `xcodebuild test` çalıştırır, örnek
  uygulamayı iOS ve macOS için derler ve DocC dokümantasyonunu yayımlar.

Testleri yerelde çalıştırmak için:

```sh
swift test                                    # macOS
xcodebuild test -scheme SwiftUIDataVisualization \
  -destination 'platform=iOS Simulator,name=iPhone 17'
```

## Yol haritası
